# Support

## Where to get help

- **Bug or feature request?** Open an issue at https://github.com/GeneGulanesJr/PiSubagent/issues (use the bug / feature templates).
- **Security vulnerability?** Email `gulanesgene@gmail.com` privately (do NOT open a public issue) — see [SECURITY.md](SECURITY.md).
- **General questions or ideas?** GitHub Discussions at https://github.com/GeneGulanesJr/PiSubagent/discussions.

## What to include in a bug report

- `node -v` output (we require Node 22+).
- `npm test` output (full, not truncated).
- Reproduction steps — minimal `subagent(...)` invocation that triggers the bug.
- Affected mode (single / parallel / chain).
- Expected vs actual behavior.

## Maintainer response time

Best-effort, no SLA. Critical bugs (security, data loss) prioritized; questions and feature requests addressed when time permits.
