# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

Earlier versions are not maintained.

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security problems.**

Email **gulanesgene@gmail.com** with:
- A short description of the issue
- Reproduction steps or a proof-of-concept
- Impact assessment (who is affected, what is the worst case)

You can expect an initial response within 7 days. We'll work with you on a coordinated disclosure timeline.

## Disclosure Timeline

- Triage within 7 days.
- Patch released as soon as a fix is verified.
- CVE assignment on request.
